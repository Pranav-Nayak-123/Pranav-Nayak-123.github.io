# Pranav Nayak · Portfolio

Personal portfolio: my journey, projects, research and contact links.

**Live:** https://pranav-nayak-123.github.io/

Plain HTML, CSS and JavaScript with no build step. It is hosted on GitHub Pages from the `main` branch.

## Edit and redeploy

- Content lives in `index.html` (journey timeline, project cards, research, skills).
- Styles are in `styles.css` (colour tokens at the top; dark and light themes).
- `main.js` handles the theme toggle, the scroll effects, project filters and the ball-tracking hero animation.

To preview locally, open `index.html` in a browser. To publish, commit and push to `main`; Pages updates in about a minute.
